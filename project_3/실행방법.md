# Book / Sboard2(공지사항) — 전체 실행 방법

boot3(백엔드) + front3(프론트엔드)에 새로 추가된 도서/공지사항 기능을
처음부터 실행하고 확인하는 방법을 정리한 문서입니다.

---

## 1️⃣ 백엔드(boot3) 준비

### 1) Oracle DB에 더미 데이터 넣기
`dummy_data_book_sboard2.sql` 파일을 SQL*Plus나 SQL Developer로 실행합니다.
이 안에 관리자 계정도 같이 만들어집니다.

```
이메일: admin_test@thejoa703.com
비밀번호: admin1234
```

### 2) 코드 반영 확인
아래 파일들이 실제 프로젝트에 다 들어가 있는지 확인합니다.

```
entity/Book.java, entity/Sboard2.java, entity/AppUser.java(수정본)
repository/BookRepository.java, repository/Sboard2Repository.java
mapper/BookMapper.java, mapper/Sboard2Mapper.java + resources/mapper/*.xml
service/BookService.java, service/Sboard2Service.java
dto/BookDto.java, dto/Sboard2Dto.java
controller/BookController.java, controller/Sboard2Controller.java
config/SecurityConfig.java   ★ @EnableMethodSecurity 추가된 버전인지 꼭 확인!
exception/GlobalExceptionHandler.java
```

### 3) 실행

```bash
./gradlew clean bootRun
```

콘솔에 빨간 에러 없이 `Started Boot3Application`이 뜨면 정상입니다.

### 4) Swagger로 직접 확인

1. 브라우저에서 `http://localhost:8080/swagger-ui/index.html` 접속
2. `Book Api`, `Notice(Sboard2) Api` 그룹이 보이는지 확인
3. `/api/users/login`(또는 `/auth/login`)에
   `email: admin_test@thejoa703.com`, `password: admin1234` 입력 → JWT 발급
4. 우측 상단 자물쇠 아이콘에 `Bearer {받은 토큰}` 입력
5. `POST /api/books`, `POST /api/notices`가 관리자로는 성공, 로그인 안 했거나
   일반회원으로는 403이 뜨는지 확인

---

## 2️⃣ 프론트엔드(front3) 준비

```bash
unzip front3.zip
cd front3
npm install
npm run dev
```

브라우저에서 `http://localhost:3000` 접속

### 흐름
1. `/login`에서 방금 만든 관리자 계정으로 로그인 (또는 구글/카카오/네이버 버튼)
2. 상단 메뉴에 `📚 BOOK`, `📢 NOTICE`가 보이고, **관리자로 로그인했을 때만**
   `📘 도서등록`, `📝 공지작성` 메뉴가 추가로 보임
3. `/books/new`, `/notices/new`에서 등록 → `/books`, `/notices`에서 목록 확인
   → 상세페이지 클릭
4. 일반회원 계정으로 로그인해서 `/books/new` 직접 접속 시
   "접근 권한이 없습니다" 화면이 뜨는지 확인
   (URL로 직접 들어가도 실제 저장은 백엔드가 403으로 최종 차단)

## 3️⃣ 테스트 코드 실행 방법

```bash
cd front3

```

## ⚠️ 막힐 때 체크리스트

| 증상 | 확인할 것 |
|---|---|
| Swagger에 book/notices 안 보임 | 서버 완전 재시작했는지, `/v3/api-docs`에 직접 접속해서 경로 있는지 |
| 도서등록했는데 403 | 로그인한 계정의 `role`이 `ROLE_ADMIN`인지 (더미 SQL의 admin 계정 사용했는지) |
| 관리자인데도 403 | `SecurityConfig.java`에 `@EnableMethodSecurity(prePostEnabled = true)` 있는지 |
| 프론트에서 로그인 안 됨 | 백엔드가 `localhost:8080`에서 떠 있는지, CORS 설정 확인 |
| `npm test` 실패 | `npm install` 제대로 됐는지, Node 버전(18+ 권장) 확인 |
