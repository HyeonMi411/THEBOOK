# BookStore 전체 프로젝트 실행 방법 (boot3 + front3 최종본)

도서/공지사항/장바구니/주문/카카오페이 결제/국립중앙도서관 검색까지 포함된
전체 프로젝트를 처음부터 실행하는 방법입니다.

---

## 0. 사전 준비물

| 항목 | 버전/확인방법 |
|---|---|
| Java | 17 (`java -version`) |
| Node.js | 16 이상 권장 (`node -v`) |
| Oracle DB | XE 등, 리스너 1521 포트 |
| Redis | 6379 포트 (세션/캐시용) |
| Gradle | boot3 안에 `./gradlew` 포함되어 있어 별도 설치 불필요 |

---

## 1. Oracle DB 준비

1. Oracle에 접속해서 `boot` 계정(스키마)을 만들어둡니다. (`application.yml`의
   `spring.datasource.username: boot` 과 일치해야 합니다)
2. `ddl-auto: update` 설정이라 애플리케이션을 처음 띄우면 필요한 테이블
   (`APP_USER`, `BOOK`, `SBOARD2`, `BOOK_STOCK`, `CART`, `CART_ITEM`, `ORDERS`,
   `ORDER_ITEMS` 등)이 **자동으로 생성**됩니다. 테이블을 미리 만드실 필요는 없습니다.
3. (선택) 더미데이터를 넣고 싶으면, boot3를 **한 번 실행해서 테이블이 다 생성된
   뒤** 아래 순서로 SQL을 실행하세요.
   ```
   1) dummy_data_book_sboard2.sql   (도서 20권 + 공지사항 20건 + 관리자 계정)
   2) dummy_data_book_stock.sql     (그 20권에 재고 채워넣기)
   ```
   관리자 테스트 계정: `admin_test@thejoa703.com` / `admin1234`

## 2. boot3 (백엔드) 실행

### 2-1. 환경변수(.env) 준비
`boot3` 폴더 최상위에 `.env` 파일을 만들고 아래 값을 채웁니다.

```env
# JWT
JWT_SECRET=아무거나_32자_이상의_임의문자열

# 소셜로그인 (구글/카카오/네이버 개발자센터에서 각각 발급)
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
KAKAO_CLIENT_ID=
NAVER_CLIENT_ID=
NAVER_CLIENT_SECRET=

# ★카카오페이 결제 (카카오 디벨로퍼스 > 내 애플리케이션 > [앱] > [어드민 키])
KAKAO_PAY_ADMIN_KEY=
# 테스트 단계에서는 비워두면 자동으로 카카오 공식 테스트용 cid(TC0ONETIME)를 씁니다.
KAKAO_PAY_CID=

# ★국립중앙도서관 도서검색 (비워두면 boot1 원본의 테스트용 키가 기본값으로 사용됩니다.
#   안 되면 국립중앙도서관 오픈API 홈페이지에서 본인 명의로 새로 발급받아 넣어주세요)
NL_API_KEY=

# 프론트엔드 주소 (카카오페이 결제완료/취소/실패 리다이렉트 URL을 만드는 데 사용)
FRONTEND_BASE_URL=http://localhost:3000

# DB (비밀번호는 실제 값으로)
DB_PASSWORD=
```

> ⚠️ `KAKAO_PAY_ADMIN_KEY`가 없으면 결제준비(`/api/payments/kakao/ready`) 호출이
> 실패합니다. 발급 방법: 카카오 디벨로퍼스(https://developers.kakao.com) 로그인 →
> 내 애플리케이션 → 앱 선택 → **[앱] → [어드민 키]** 메뉴에서 확인 (오너 계정만 조회 가능)

### 2-2. Redis 실행
```bash
redis-server
```

### 2-3. boot3 실행
```bash
cd boot3
./gradlew bootRun
```
`http://localhost:8080` 에서 뜹니다.

### 2-4. Swagger로 API 확인
```
http://localhost:8080/swagger-ui/index.html
```
`Book Api`, `Notice(Sboard2) Api`, `Cart Api`, `Order Api`, `Payment Api` 그룹이
전부 보이면 정상입니다.

## 3. front3 (프론트엔드) 실행

```bash
cd front3
npm install
npm run dev
```
`http://localhost:3000` 에서 뜹니다.

> front3의 `next.config.js`에 `eslint.ignoreDuringBuilds: true`가 설정되어 있어서,
> 스타일(ESLint) 위반이 있어도 빌드/실행 자체는 막히지 않습니다.

### 프로덕션 빌드로 확인하려면
```bash
npm run build
npm start
```

## 4. 전체 기능 흐름 한눈에 보기

| 화면 | 경로 | 비고 |
|---|---|---|
| 도서 목록/상세 | `/books`, `/books/[id]` | 재고배지, 장바구니담기/바로구매 버튼 |
| 도서 등록/수정 | `/books/new` | **관리자 전용** |
| 국립중앙도서관 검색 | `/books/national-library` | 전체공개, 저장은 관리자 전용 |
| 공지사항 | `/notices`, `/notices/[id]` | 상세조회시 조회수 자동 증가 |
| 공지사항 작성 | `/notices/new` | **관리자 전용** |
| 장바구니 | `/cart` | 로그인 회원 전체 |
| 주문/결제확인 | `/order/checkout` | 카카오페이 결제요청 |
| 결제완료/취소/실패 | `/payment/complete`, `/payment/cancel`, `/payment/fail` | 카카오 리다이렉트 처리 |
| 내 주문내역 | `/mypage/orders`, `/mypage/orders/[id]` | |
| 마이페이지 | `/mypage` | 프로필, 팔로우 등 |

**결제 전체 흐름**: 로그인 → 도서상세(구매버튼) → 장바구니 → 주문확인 →
카카오페이 결제창 → 결제완료(재고 실제 차감) → 주문내역 확인
(자세한 Swagger 테스트 절차는 별도로 드린 `BookStore_결제기능_Swagger테스트가이드.md` 참고)

## 6. 자주 막히는 부분 (Troubleshooting)

| 증상 | 원인 / 해결 |
|---|---|
| `@RequestParam` 관련 500 에러 | 컴파일러 `-parameters` 옵션 미적용 환경 문제. 이미 모든 컨트롤러에서 `name=` 명시로 해결되어 있음 |
| `KAKAO_PAY_ADMIN_KEY` 없이 결제준비 호출시 401 | 어드민 키 미발급/오타. 2-1번 참고 |
| Swagger에서 `pg_token` 테스트가 안 됨 | 실제 결제창을 한 번 거쳐야 나오는 값입니다. 별도 가이드 문서 참고 |
| 로그인 후 `<Link> multiple children` 에러 | 이미 수정 완료 (AppLayout.js 장바구니 메뉴 템플릿 리터럴로 통일) |
| `next build`에서 ESLint 에러로 실패 | 이미 수정 완료 (`@babel/eslint-parser` 교체 + `next.config.js` 설정) |
| 재고 0인 도서로 장바구니/주문 시도시 거부됨 | 정상 동작입니다. `PATCH /api/books/{id}/stock`(관리자 전용)으로 재고를 먼저 채워주세요 |
